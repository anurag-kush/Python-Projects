# Python Projects 🐍

A collection of Python projects built to strengthen core programming concepts and gradually evolve into production-ready applications.

This repository serves as a portfolio of practical Python projects covering problem-solving, object-oriented programming, automation, and AI-ready application development.

---

## Repository Structure

### Main Branch

Projects that are completed and ready for review.

| Project | Description |
|---------|-------------|
| Caesar Cipher | Encrypts and decrypts text using the Caesar Cipher algorithm. Demonstrates string manipulation, functions, and modular programming. |
| RPG Character Creation | Console-based RPG character generator showcasing user input, conditionals, functions, and basic game logic. |
